# ⚾ MLB Stats & Analytics Hub

A comprehensive, interactive website for baseball statistics and analytics featuring modern design, real-time visualizations, and responsive layouts.

![MLB Analytics](https://img.shields.io/badge/MLB-Analytics-blue?style=for-the-badge)
![Version](https://img.shields.io/badge/version-1.0.0-green?style=for-the-badge)
![Status](https://img.shields.io/badge/status-ready-success?style=for-the-badge)

## 🌟 Features

- 📊 **Interactive Statistics** - Sortable tables, real-time search, and advanced filters
- 📈 **Data Visualization** - Beautiful charts powered by Chart.js
- 🏆 **Leader Boards** - Track top performers in batting and pitching categories
- 📱 **Fully Responsive** - Works perfectly on mobile, tablet, and desktop
- 🎥 **Video Integration** - Embedded highlights and analysis
- ❓ **Comprehensive FAQ** - Detailed explanations of stats and metrics
- 🎨 **Modern Design** - Clean UI with smooth animations and transitions

## 🚀 Quick Start

1. **Open the website**
   ```bash
   # Simply open index.html in your browser
   open index.html
   ```

2. **Explore the pages**
   - Home: Overview and featured content
   - Statistics: Detailed player stats with filters
   - Stat Leaders: Top performers across categories
   - FAQ: Learn about baseball metrics

3. **Customize** (optional)
   - Edit colors in `styles.css`
   - Update player data in HTML files
   - Add your own images to `assets/` folder

## 🎨 Customization

### Change Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary-color: #0051BA;    /* Blue */
    --secondary-color: #D50032;  /* Red */
    --dark-bg: #0a1628;         /* Dark Navy */
}
```

### Update Content
- Player stats: Edit tables in HTML files
- Videos: Replace YouTube IDs in iframe src
- Images: Add to `assets/` folder with correct names

### Add Features
- JavaScript functions in `script.js`
- Styles in `styles.css`
- New pages follow existing structure
